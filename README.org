* Introduction

#+begin_quote
Looks matter. It is a good thing to have utility with a good rice.
#+end_quote

A single-host NixOS + home-manager configuration, wired together with [[https://flake.parts][flake-parts]] instead of one monolithic =flake.nix=. Every file under [[./modules][modules/]] auto-imports itself via =lib.fileset= --- see [[./flake.nix][flake.nix]] --- so adding a new module is just adding a new =.nix= file, no import list to maintain.

* Repository layout

#+begin_example
.
├── flake.nix / flake.lock      # flake-parts entrypoint; auto-imports modules/
├── modules/
│   ├── *.nix                   # flat, single-purpose modules (see table below)
│   ├── accounts/                # email + pass/ripasso
│   ├── agenix/                  # secrets management + encrypted secrets
│   ├── browsers/                # Firefox, userChrome/userContent, w3m
│   ├── desktop/                 # common desktop bits + GNOME
│   ├── discord/                 # Vesktop + Vencord
│   ├── emacs/                   # org-tangled Emacs config
│   ├── hosts/nixpavilion/       # host-specific config, disko layout, hardware scan
│   ├── shell/                   # zsh + starship
│   └── users/                   # per-user home-manager entrypoints
└── TODO.md
#+end_example

Every module follows the same shape: a top-level =flake.nixosModules.<name>= and/or =flake.homeModules.<name>= attribute, picked up automatically and wired into the =nixpavilion= host in [[./modules/nixos.nix][modules/nixos.nix]].

* Installation

#+begin_quote
Assumes an installer ISO is already booted. See the [[https://nixos.org/manual/nixos/stable/][NixOS Manual]] for more general background.
#+end_quote

** 🧪 Enable experimental features

Flakes and the =nix= command aren't on by default:

#+begin_src sh
sudo -i
export NIX_CONFIG="experimental-features = nix-command flakes"
#+end_src

** ↙️ Clone this repo

#+begin_src sh
mkdir -p /tmp
cd /tmp
git clone --depth=1 https://github.com/rachitvrma/dotfiles.git
#+end_src

** 💾 Partition with Disko

Run the latest [[https://github.com/nix-community/disko][nix-community/disko]] rather than the nixpkgs-pinned version. Confirm =disko-config.nix= matches the target host (defaults to [[./modules/hosts/nixpavilion][nixpavilion]]):

#+begin_src sh
cd /tmp/dotfiles/modules/hosts/nixpavilion
nix run github:nix-community/disko/latest -- --mode destroy,format,mount ./disko-config.nix
#+end_src

** 🐧 Install

#+begin_src sh
mkdir -p /mnt/etc
cp -r /tmp/dotfiles /mnt/etc/nixos
nixos-install --no-root-passwd --root /mnt --cores 8 --max-jobs 1 --flake /mnt/etc/nixos#nixpavilion
umount -R /mnt
reboot
#+end_src

** 💻 Post-install

*** Set your password

#+begin_src sh
passwd $USER
#+end_src

*** Edit config without =sudo=

Move =/etc/nixos= into your home directory so you can edit and rebuild without root ([[https://wiki.nixos.org/wiki/NixOS_configuration_editors#Editing_as_normal_user][source]]):

#+begin_src sh
mkdir ~/etc
sudo mv /etc/nixos ~/etc/
sudo chown -R $(id -un):users ~/etc/nixos
sudo ln -s ~/etc/nixos /etc/
#+end_src

*** GPG / pass restoration

#+begin_quote
*Important:* Do this before the first =home-manager switch= / =nh os switch= after a reinstall --- Nix can't manage your GPG secret key material, and =pass=/=pass-secret-service=/the email module's =passwordCommand= will all fail (blocking the rebuild) until it's restored.
#+end_quote

Before wiping the old system:

#+begin_src sh
gpg --homedir ~/.local/share/gnupg --export-secret-keys --armor > gpg-backup.asc
#+end_src

Also make sure =~/.password-store= is backed up or pushed to a remote --- the key alone decrypts nothing without the encrypted store itself.

After reinstall, before rebuilding:

#+begin_src sh
mkdir -p ~/.local/share/gnupg
gpg --homedir ~/.local/share/gnupg --import gpg-backup.asc
gpg --homedir ~/.local/share/gnupg --edit-key <keyid> trust   # choose 5 (ultimate)
git clone <your-pass-store-remote> ~/.password-store
#+end_src

#+begin_quote
*Note:* =programs.gpg.homedir= is =~/.local/share/gnupg=, not =~/.gnupg=.
#+end_quote
