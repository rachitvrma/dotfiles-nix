* How modules are wired

- =flake.nix= collects every =.nix= file under the repo with =lib.fileset=. Three kinds of file are skipped: =flake.nix= itself, any =secrets.nix= (agenix recipient lists), and any file whose /name/ starts with =_= (used for helper files that are =import=-ed or =callPackage=-d by hand, such as =modules/emacs/packages/_default.nix=).
- Each module exposes =flake.nixosModules.<name>= and/or =flake.homeModules.<name>=.
- [[../modules/nixos.nix][modules/nixos.nix]] builds =nixosConfigurations.nixpavilion= from /all/ =nixosModules= and gives the user /all/ =homeModules=. There is no per-host opt-in: if a module exists, it is enabled. To turn something off, set its =enable = false= inside the module (as is done for [[../modules/desktop/terminal/kitty.nix][kitty.nix]]) rather than deleting the file.
- Home-manager runs as a NixOS module (=useGlobalPkgs=, =useUserPackages=). Clobbered files are moved to the trash (=backupCommand=) instead of leaving =.hm-bak= clutter.

* Adding a module

Create =modules/<anything>.nix= (or a folder) with this shape; it is picked up on the next rebuild:

#+begin_src nix

  {
    flake.nixosModules.example = { pkgs, ... }: {
      environment.systemPackages = [ pkgs.hello ];
    };

    flake.homeModules.example = { pkgs, ... }: {
      programs.bat.enable = true;
    };
  }

#+end_src

Remember that new files must be =git add=-ed before a flake build can see them. Helper files that should /not/ be auto-imported get a leading underscore.

* Conventions worth knowing

- *The repo must live at =~/etc/nixos=.* [[../modules/nixos.nix][modules/nixos.nix]] (=dotfilesDir=), =nh=, and the Emacs module (out-of-store symlinks for =init.el= / =early-init.el=) all assume that path. [[../scripts/00-move_nixos-config.sh][scripts/00-move_nixos-config.sh]] sets it up.
- *Editing =Config.org= needs no rebuild.* The Emacs init files are symlinked straight into the working tree. Saving =Config.org= re-tangles it (=org-auto-tangle=); run =remacs= to restart the Emacs daemon.
- *The username =krish= is hard-coded in several places* (see below).

* Adapting this config to another user

Search the tree for the string =krish= and replace it. The places that matter:

- [[../modules/users/krish.nix][modules/users/krish.nix]] --- the account itself. *Change =initialPassword= (it is a placeholder) or remove it and use =passwd= after install.*
- [[../modules/nixos.nix][modules/nixos.nix]] --- =dotfilesDir= and =home-manager.users.krish=.
- [[../modules/nixsettings.nix][modules/nixsettings.nix]] --- =trusted-users= and the =nh= flake path.
- [[../modules/desktop/commonDesktop.nix][commonDesktop.nix]], [[../modules/desktop/noctalia/greeter.nix][noctalia/greeter.nix]], [[../modules/desktop/noctalia/noctalia-config.toml][noctalia-config.toml]] --- avatar, greeter user, wallpaper directory.
- [[../modules/virtualisation.nix][modules/virtualisation.nix]] --- extra groups.
- [[../modules/agenix/secrets/secrets.nix][agenix/secrets/secrets.nix]] --- the public key the secrets are encrypted to. Re-encrypt the =.age= files with your own key (=agenix -r=) or delete the secrets you do not need.

For a second machine see [[./new-host.org][new-host]].
