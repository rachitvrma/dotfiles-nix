#+TITLE: Nix / NixOS / Flakes --- learning resources

Back to the [[../README.org][README]].

* The book from Reddit

- *[[https://nixos-and-flakes.thiscute.world/][NixOS \& Flakes Book]]* --- ryan4yin. Flake-parts-adjacent patterns, home-manager, and the module system in depth.

* Official / foundational docs

- *[[https://nix.dev/][nix.dev]]* --- task-oriented "get things done" guide.
- *[[https://nix.dev/manual/nix/stable/][Nix Reference Manual]]* --- the language/CLI spec.
- *[[https://nixos.org/manual/nixpkgs/stable/][Nixpkgs Manual]]* / *[[https://nixos.org/manual/nixos/stable/][NixOS Manual]]*.
- *[[https://nixos.org/guides/nix-pills/][Nix Pills]]* --- build Nix up from first principles.

* Flake-centric onboarding

- *[[https://zero-to-nix.com/][Zero to Nix]]* --- Determinate Systems' flakes-first onboarding, plus per-language dev-shell guides.
- *Wombat's Book of Nix* --- a more concept-first second opinion.

* Reference / search tools

- *[[https://noogle.dev/][Noogle]]* --- search =lib.*= by shape/signature.
- *[[https://home-manager-options.extranix.com/][Home Manager Option Search]]*
- *[[https://search.nixos.org/][search.nixos.org]]* --- packages + options.
- *[[https://mynixos.com/][MyNixOS]]* --- cross-referenced options/packages.

* Curated meta-lists

- *[[https://github.com/nix-community/awesome-nix][awesome-nix]]* --- community-maintained master list.
- *[[https://ianthehenry.com/posts/how-to-learn-nix/][How to Learn Nix]]* --- the language specifically, not NixOS or flakes.
- *[[https://www.vimjoyer.com/course/][VimJoyer's Interactive Course]]* --- game-like interactive course on Nix.
