* Introduction

#+begin_quote
Looks matter. It is a good thing to have utility with a good rice.
#+end_quote

A single-host NixOS + home-manager configuration, wired together with [[https://flake.parts][flake-parts]] instead of one monolithic =flake.nix=. Every file under [[./modules][modules/]] auto-imports itself via =lib.fileset= --- see [[./flake.nix][flake.nix]] --- so adding a new module is just adding a new =.nix= file, no import list to maintain. Details in [[./docs/architecture.org][docs/architecture.org]].

* Quick start

Fresh machine: follow [[./docs/installation.org][docs/installation.org]]. Already installed:

#+begin_src sh

  cd ~/etc/nixos
  nix flake update
  nos            # alias for: nh os switch

#+end_src

The repo is expected to live at =~/etc/nixos= (see [[./docs/architecture.org][architecture]] for why).
